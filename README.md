A comprehensive **manufacturing ERP dashboard** (Cadra) with production metrics, order tracking, machine status monitoring and analytics. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🏭 **Production metrics** — output, efficiency, downtime KPIs
- 🔧 **Machine status** — real-time operational state indicators
- 📋 **Order tracking** — work orders with progress & priority
- 📊 **Analytics charts** — production trends & performance
- 🚨 **Alert system** — maintenance & threshold notifications
- 🌙 **Dark themed** professional UI
- 📱 **Fully responsive** — works on all screen sizes
- ⚡ **Zero dependencies** — no libraries
